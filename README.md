notification_system
--------

Download [the latest JAR][2] or grab via Maven:
```xml
<dependency>
  <groupId>com.subgraphreverttest.awesome_obfuscations</groupId>
  <artifactId>awesome_obfuscations</artifactId>
  <version>1.3.3</version>
</dependency>
```
or Gradle:
```groovy
compile 'com.subgraphreverttest.awesome_obfuscations:awesome_obfuscations:1.3.3'
```

Snapshots of the development version are available in [sonatype's `snapshots` repository][snap].

awesome-obfuscations requires at minimum Java 8 or Android 2.3.
